# Enable search indexing at launch

Use this procedure when the site content is ready and Riccardo asks to make the website indexable. Until then, every page has a shared `<meta name="robots" content="noindex">` in `src/_includes/base.njk`, and Netlify adds `X-Robots-Tag: noindex` to all responses through `netlify.toml`.

1. **Choose the pages to index.** Review the finished Home, About, CV, and Contact pages. Decide what to do with `/terminal/`, `/readme/`, `/web90/`, and `/designs/`: remove the unused design routes from the public build or keep a page-specific `noindex` on them. Confirm the canonical production domain and that it resolves.
2. **Remove the site-wide block.** Delete the robots meta tag from `src/_includes/base.njk` and the `X-Robots-Tag` rule from `netlify.toml` (delete the file if it has no other settings). Update the source assertion in `tests/homepages.spec.js` to check the chosen policy for each route. Do not add a site-wide `Disallow: /` to `robots.txt`: crawlers must be able to reach a page to read its indexing directives. [Google: `noindex` requirements](https://developers.google.com/search/docs/crawling-indexing/block-indexing).
3. **Verify the build.** Run `npm run test:visual`. Inspect generated HTML for the intended pages and check that no unwanted `noindex` remains. Review any other indexing controls in the site and Netlify settings.
4. **Deploy and verify production.** Commit and push the change, wait for the Netlify production deploy, then inspect both the HTML and HTTP response headers on the canonical domain for Home and at least one inner page. Confirm there is no `noindex` meta tag or `X-Robots-Tag: noindex` on pages meant to be indexed. Check `/robots.txt` if present. Netlify's global header rules are described in its [custom headers documentation](https://docs.netlify.com/manage/routing/headers/).
5. **Ask search engines to revisit.** In Google Search Console, inspect the canonical homepage and request indexing if the property is available. A sitemap can help discovery once the final public routes are settled. Monitor the indexing report; a request does not guarantee inclusion or immediate crawling. [Google: request a recrawl](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl).

If launch is postponed again, restore the site-wide meta tag and Netlify header, redeploy, and verify their presence on production.
